## 本机核验

合成面板的预处理、七模型训练/五档评估、参数更新、生成/四指标计算通过。三种方式的旧参数键加载兼容；收益6/成交量6与收益6/成交量3两组边界下，对照原日频扩散实现的CPU采样逐值相同。RetAC、VolC和KL与固定上游数值函数核对通过。

仓库没有包含原始行情、逐日记录、生成数组、权重、训练日志、服务器配置或凭据。原完整研究项目与报告保持在本地，不由本发布覆盖。
